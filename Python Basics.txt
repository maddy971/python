* Loops : to repeat the same statements again and again loops are used in loops mainly two types :

i) for loop : when we know the number of repetition we use for loop. 
   in for loop we use keyword 'in' to check the existence of a value.
   and we use range method which comes with 3 different parameters :-

	a) for i in range(int) : range with one parameter, when we pass a single parameter it starts the loop from the zero till the 		   parameter value not the parameter value.
		example : for i in range(10):
				print(i) //it prints 0-9

	b) for i in range(int,int) : range with a two parameter. when we pass two parameters first parameter to start the loop, and second 	   parameter to specify the end. 
		example : for i in range(5,15):
				print(i) // it prints only 5-15

	c) for i in range(int,int,int) : first parameter for start value, second parameter for end value and third parameter for inc/dec.
		example : for i in range(1,10,2)
				print(i) // it print 1,3,5,7,9

i)list : its used to store any type of data. it stores the data with the help of Index number list are used list are defined define using square brackets a square bracket following example demonstrate list :

ii) tuples : its a dynamic collection class this class defines only constant values. once the tuple is define it cannot be changed. its mainly designed to store constants. there is no methods for tuple to manipulate the data. in tuples we have the property by name length. which will count the number of elements in a tuple. tuples are define using a () round bracket.

iii) set : set is a dynamic collection class. it stores the data by name itself. adding and removing of data is done. by using name. in set we can use mathematical operations it supports all set operations of maths (union, intersection, difference), it can contains only unique values.

Exception Handling : to work with exceptions python introduced exception handling to trace the errors faster which will avoid abnormal termination of a program. to work with exception handling we introduced 3 keywords : 

i) try : we are going to write code which may cause errors. if error found control will be passed to the except block this will avoid the abnormal termination of program.

ii) except : this keyword is equivalent to catch. it will read the error and display an appropriate message.
  
iii) finally : its a guarantied block which will execute irrespective of errors. if the error traced it will display the error message. if there is no errors control directly passes to finally block.

in python else keyword is introduced in exception handling to display program has no errors and it executed completely.

iv) raise : its used to display our own error messages with respective our criteria.
